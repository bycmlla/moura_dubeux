VIVANT - MATERIAL ORGANIZADO

Estrutura:
- capa/
  Foto principal recomendada para o card/destaque.

- imagens_empreendimento/
  - fachadas/
  - areas_comuns/
  - apartamentos/
  Contém somente imagens visuais do empreendimento.
  NÃO contém plantas.

- plantas/
  Contém exclusivamente plantas, implantações e pavimentos.

- localizacao/
  Mapas, entorno e Praça Aquarius.

- informacoes/
  vivant.txt
  manifesto_imagens.txt

Uso recomendado no site:
1. Use capa/capa_vivant.png como imagem principal.
2. Use imagens_empreendimento/ na galeria comum.
3. Use plantas/ exclusivamente na seção "Plantas".
4. Use localizacao/ na seção de localização/entorno.
5. Use os títulos do manifesto como legendas das imagens.
6. Não mostre os nomes técnicos dos arquivos ao visitante.
