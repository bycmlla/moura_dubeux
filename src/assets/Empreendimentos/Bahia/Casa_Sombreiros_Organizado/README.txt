CASA SOMBREIROS - MATERIAL ORGANIZADO

ATENÇÃO:
O book de origem informa que o material é de uso exclusivo interno e treinamento
de corretores, com divulgação externa proibida. Verifique se existe versão comercial
autorizada antes de publicar o conteúdo em site público.

ESTRUTURA
- capa/
  Imagem principal recomendada para card / destaque.

- imagens_empreendimento/
  - fachadas/
  - areas_comuns/
  - apartamentos/
  Somente imagens visuais do empreendimento.
  NÃO contém plantas.

- plantas/
  Somente plantas, pavimentos e implantações.

- localizacao/
  Vista aérea do Caminho das Árvores e entorno.

- informacoes/
  casa_sombreiros.txt
  manifesto_imagens.txt

USO RECOMENDADO
1. Use capa/capa_casa_sombreiros.png como imagem principal.
2. Use imagens_empreendimento/ na galeria comum.
3. Use plantas/ exclusivamente na seção "Plantas".
4. Use localizacao/ na seção de localização / entorno.
5. Use os títulos do manifesto como legendas amigáveis.
6. Não exiba nomes técnicos dos arquivos ao visitante.
7. Não misture as imagens das plantas com as imagens do empreendimento.
