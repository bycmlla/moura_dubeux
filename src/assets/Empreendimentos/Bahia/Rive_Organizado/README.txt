RIVÊ - MATERIAL ORGANIZADO

Estrutura:
- capa/
  Imagem principal recomendada para card/destaque.

- imagens_empreendimento/
  - fachadas/
  - areas_comuns/
  - apartamentos/
  Somente imagens visuais do empreendimento. Não contém plantas.

- plantas/
  Plantas de unidades, pavimentos, rooftop e implantações.

- localizacao/
  Imagens do entorno, localização e mapa de pontos de interesse.

- informacoes/
  rive.txt
  manifesto_imagens.txt

Uso recomendado no site:
1. Use capa/capa_rive.png no card principal.
2. Use imagens_empreendimento/ na galeria comum.
3. Use plantas/ exclusivamente na seção Plantas.
4. Use localizacao/ na seção Localização/Entorno.
5. Use os títulos do manifesto como legendas.
6. Não exiba os nomes técnicos dos arquivos ao visitante.
