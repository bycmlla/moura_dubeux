SALVADOR 220 - MATERIAL ORGANIZADO

Estrutura:
- capa/
  Imagem principal recomendada para card e destaque.

- imagens_empreendimento/
  - fachadas/
  - areas_comuns/
  - apartamentos/
  Contém apenas imagens visuais do empreendimento.
  NÃO contém plantas.

- plantas/
  Contém plantas de apartamentos, pavimentos, rooftop e implantações.

- localizacao/
  Imagem de localização do empreendimento no Rio Vermelho.

- informacoes/
  salvador_220.txt
  manifesto_imagens.txt

Uso recomendado no site:
1. Use capa/capa_salvador_220.png no card principal.
2. Use imagens_empreendimento/ na galeria normal.
3. Use plantas/ exclusivamente na seção Plantas.
4. Use localizacao/ na seção Localização.
5. Use os títulos do manifesto como legendas amigáveis.
6. Não exiba o nome técnico do arquivo ao visitante.
